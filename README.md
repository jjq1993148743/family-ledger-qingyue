# 家庭收支本 · 青月版

一家人的日常收支记账小程序。后端以**微信云开发**为主：小程序前端 + 云函数（云开发的后端代码）+ 云数据库（云开发的数据库）+ 云存储（云开发的文件存储）；账本数据以数据库为主、本机留缓存，换手机、清缓存、重装都不丢；没网也能先记，联网自动补传。自建后端服务 + 数据库保留为备选方案。

## 功能

| 页面 | 能干啥 |
|------|--------|
| 账本 | 切换支出/收入、选分类、选家庭成员、填金额和备注，记一笔；顶部看本月收入、支出、结余；最近记录可删除 |
| 月结 | 左右切换月份，看当月收入/支出/结余、按分类的支出占比条、按成员的支出汇总 |

数据库存主本，`wx.setStorageSync`（本地缓存）只作离线暂存；云开发走 `wx.cloud`（云开发接口）微信私有链路，天然带用户身份，不用自己搭服务器、不用买域名备案、不用配 `request` 合法域名（允许请求的服务器域名）。若改用自建后端，才需要 `HTTPS`（加密传输协议）+ 已备案域名与合法域名配置。

## 怎么跑

1. 微信开发者工具 → 导入项目 → 选本目录
2. 小程序账号的 AppID 选「不使用 AppID / 测试号」（`project.config.json` 里写的是 `touristappid`）
3. 点编译，在模拟器里记一笔试试
4. 要连数据库：开通云开发环境、拿到 `envId`（云开发环境标识）并填进 `app.js`（小程序入口）；游客测试号开不了云开发，需换正经 `AppID`（小程序账号标识）

要发布成自己的小程序，把 `project.config.json` 里的 `appid` 换成你的 AppID（小程序账号的 AppID）。

## 目录

| 路径 | 说明 |
|------|------|
| `miniprogram/app.json` | 页面注册、导航栏与底部标签配置 |
| `miniprogram/app.wxss` | 全局暖色橘黄配色与衬线字体 |
| `miniprogram/utils/store.js` | 账目读写、金额格式化、汇总计算（后续改为调云数据库 / 云函数） |
| `miniprogram/pages/ledger/` | 账本页（记一笔 + 本月汇总 + 明细） |
| `miniprogram/pages/monthly/` | 月结页（月份切换 + 分类/成员统计） |
| `cloudfunctions/`（待建） | 云函数：业务逻辑、鉴权、汇总、定时任务、分享权限校验 |
| `database/`（待建） | 云数据库表结构 / 集合设计与初始化脚本 |

## 设计

米白打底、深可可棕压场、橘黄作主色、赤陶红橘记支出，中文衬线字配 Georgia 数字；顶部左对齐大标题加右上月份标签，汇总卡左宽右窄错位排布，整体暖色调，不用冷色系、不用紫色渐变、不用表情图标。
