# 家庭收支本 · 青月版

一家人的日常收支记账小程序。账本数据以云端为主、本机留缓存：换手机、清缓存、重装小程序都不丢；没网也能先记，联网自动补传。

## 功能

| 页面 | 能干啥 |
|------|--------|
| 账本 | 切换支出/收入、选分类、选家庭成员、填金额和备注，记一笔；顶部看本月收入、支出、结余；最近记录可删除 |
| 月结 | 左右切换月份，看当月收入/支出/结余、按分类的支出占比条、按成员的支出汇总 |

云端存主本，`wx.setStorageSync`（本地缓存）只作离线暂存；同一微信号换设备打开自动同步回来。云端方案建议微信云开发，需绑定正经 `AppID`（小程序账号标识）并开通云环境。

## 怎么跑

1. 微信开发者工具 → 导入项目 → 选本目录
2. 小程序账号的 AppID 选「不使用 AppID / 测试号」（`project.config.json` 里写的是 `touristappid`）
3. 点编译，在模拟器里记一笔试试

要发布成自己的小程序，把 `project.config.json` 里的 `appid` 换成你的 AppID（小程序账号的 AppID）。

## 目录

| 路径 | 说明 |
|------|------|
| `miniprogram/app.json` | 页面注册、导航栏与底部标签配置 |
| `miniprogram/app.wxss` | 全局月白/黛青配色与衬线字体 |
| `miniprogram/utils/store.js` | 账目读写、金额格式化、汇总计算 |
| `miniprogram/pages/ledger/` | 账本页（记一笔 + 本月汇总 + 明细） |
| `miniprogram/pages/monthly/` | 月结页（月份切换 + 分类/成员统计） |

## 设计

月白打底、黛青压场、朱赭记支出、青瓷记收入，中文衬线字配 Georgia 数字；顶部左对齐大标题加右上月份标签，汇总卡左宽右窄错位排布，不用紫色渐变，不用表情图标。
