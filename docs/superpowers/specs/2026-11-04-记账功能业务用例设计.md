# 记账功能业务用例设计

| 项 | 内容 |
|---|---|
| 日期 | 2026-11-04 |
| 项目 | 家庭收支本 · 青月版（微信小程序） |
| 硬约束 | 纯本地存储、不联网、不用云开发、不用后端（`README.md:3`） |
| 交付形态 | 业务用例：谁 · 在哪个页面 · 能干什么 · 达到什么目的 |
| 本轮状态 | 仅设计，未改任何业务代码 |

## 一、范围裁定

| 项 | 结论 | 理由 |
|---|---|---|
| 截图 `OCR`（图片文字识别） | 不做 | 用户点名砍掉 |
| 自动同步微信 / 支付宝 / 银行流水 | 不做 | 用户点名砍掉；最麻烦的一档：要登录授权、各家账单格式不一、必须联网加后端、隐私合规、接口一变就失效 |
| 多币种 | 不做 | 统一人民币 |
| 社区 | 不做 | 与记账无关 |
| `AI`（人工智能） | 不做 | 连带的「语音 / 一句话智能解析」一并砍掉，本质靠 `AI`，不做半吊子 |
| 除以上五项 | 全做 | 用户确认「其他的都要」 |

## 二、角色

| 角色 | 是谁 | 权限边界 |
|---|---|---|
| 记账人 | 我 / 家人，可切成员身份 | 记、改、删、看、用模板、切账本 |
| 管理员 | 家长 | 记账人全部权限，另加管配置、设预算、管权限、导出与恢复 |
| 只读成员 | 家人 / 查看者 | 只能看流水与月结，记改删按钮隐藏 |
| 系统 | 小程序自身，非真人 | 补记周期账、算预算、去重、生成导出文件 |

## 三、页面

| 页面 | 状态 | 文件 | 定位 |
|---|---|---|---|
| 账本页 | 现有，增强 | `miniprogram/pages/ledger/ledger` | 记一笔 + 本月概览 + 预算余量 |
| 流水页 | 新增 | `miniprogram/pages/stream/stream` | 全部账目、日历、搜索、编辑、撤销 |
| 月结页 | 现有，增强 | `miniprogram/pages/monthly/monthly` | 月度复盘、占比、预算执行、下钻 |
| 设置页 | 新增 | `miniprogram/pages/settings/settings` | 分类、账户、账本、模板、周期、成员、预算、导出 |

页面注册见 `miniprogram/app.json:2`，底部 `Tab`（标签页）见 `miniprogram/app.json:13`，建议扩为四个：账本 / 流水 / 月结 / 我的。

## 四、业务用例

| 编号 | 谁 | 在哪个页面 | 可以干什么 | 达到什么目的 |
|---|---|---|---|---|
| A1 | 记账人 | 账本页 | 切支出 / 收入，输金额（支持 `12+8` 直接算），选分类、账户、成员、日期（可补昨天以前）、填备注、附票据照片，点「记下」 | 一次把一笔真实消费记全，不用回家补、不漏字段 |
| A2 | 记账人 | 账本页 | 选模板（买菜 / 通勤 / 工资）一键带入金额、分类、账户、备注，只改金额就存 | 高频固定支出不用每次重填 |
| A3 | 记账人 | 账本页 | 记完保留上次分类、账户、成员，只清金额和备注 | 连着记几笔不重复选 |
| A4 | 记账人 | 账本页 | 顶部看本月收入 / 支出 / 结余、预算剩余，超支标红 | 记之前就知道这个月还剩多少能花 |
| A5 | 记账人 | 账本页 | 切当前账本（日常 / 旅行 / 装修） | 专项花费不混进家庭日常账 |
| A6 | 系统 | 账本页 | 冷启动 / 回前台时按周期规则补记到期账，同日同规则只补一次 | 房租、工资不因忘记打开而漏记 |
| A7 | 记账人 | 账本页 | 点最近几笔进详情，直接编辑或删除 | 记错当场改，不用翻二级页 |
| B1 | 全部角色 | 流水页 | 按日分组看全部账目（不再只显 8 笔），每日小计收入 / 支出 | 完整还原钱怎么花的 |
| B2 | 全部角色 | 流水页 | 日历视图点某天看当天明细、跨天补记 | 对账、想起漏记的那天 |
| B3 | 记账人 | 流水页 | 按分类 / 成员 / 账户 / 账本 / 类型 / 日期 / 金额区间 / 关键词筛选 | 从几百笔里一秒找到「上周给爸买药那笔」 |
| B4 | 记账人 | 流水页 | 编辑任意一笔：金额、分类、账户、成员、日期、备注、票据 | 记错、选错、输错都能纠正 |
| B5 | 记账人 | 流水页 | 删除后 5 秒内撤销，或进回收站保留 7 天 | 手滑删了不丢数据 |
| B6 | 全部角色 | 流水页 | 点开票据照片看原图 | 核对小票、报销有凭 |
| B7 | 只读成员 | 流水页 | 只能看，记改删按钮隐藏 | 给家人看账不担心被误改 |
| C1 | 全部角色 | 月结页 | 左右切月份，看收入 / 支出 / 结余、笔数 | 月底复盘有个准数 |
| C2 | 全部角色 | 月结页 | 按分类 / 成员 / 账户 / 账本看支出占比与排行 | 知道钱主要花在哪个口子、谁花的 |
| C3 | 全部角色 | 月结页 | 看总预算与分类预算执行、超支标红、对比上月趋势 | 下个月知道该收哪一刀 |
| C4 | 管理员 | 月结页 | 点分类下钻到该分类的流水 | 从「伙食花了 2000」直接看到哪笔记多了 |
| D1 | 管理员 | 设置页 | 增删改分类（名称 / 图标 / 颜色 / 排序），支出收入各一套 | 分类贴合自家口径，不再被写死的 7 + 5 个困住 |
| D2 | 管理员 | 设置页 | 管账户（现金 / 微信 / 支付宝 / 银行卡），可停用不删历史 | 记账能选资金出处，停用旧卡不丢旧账 |
| D3 | 管理员 | 设置页 | 管账本（建 / 改名 / 切换 / 删，删除二次确认并说明数据去向） | 旅行、装修专项账分开算 |
| D4 | 管理员 | 设置页 | 管模板（把常记的一笔存成模板、排序、删除） | 把 A2 的提速能力自己攒出来 |
| D5 | 管理员 | 设置页 | 管周期账（金额 / 分类 / 账户 / 周期 / 起始日 / 启停） | 房租、工资、话费不用月月手敲 |
| D6 | 管理员 | 设置页 | 设成员与权限：谁能记 / 改 / 删，谁只读 | 一家人共用一台设备也不越权 |
| D7 | 管理员 | 设置页 | 设总预算、各分类预算、超支提醒开关 | 把 A4 / C3 的阈值定下来 |
| D8 | 管理员 | 设置页 | 导出 `CSV`（逗号分隔表格，按时间 / 账本筛选）并转发或复制；导入备份恢复 | 数据只在本地，换手机、清缓存也不丢 |
| D9 | 管理员 | 设置页 | 看本地占用、清理票据图片、清空账本数据 | 本地存储不被图片撑爆 |

## 五、约束与落地替代

| 想做的事 | 硬约束 | 落地办法 |
|---|---|---|
| 语音 / 一句话 / `OCR` / 流水自动同步 / 多币种 / 社区 / `AI` | 用户点名砍掉；`README.md:3` 纯本地不联网 | 不做，不预留入口 |
| 真·多人跨设备协同 | 无云开发、无后端 | 同一台设备上的成员切换 + 本地角色开关（D6），不做跨设备同步 |
| 票据照片 | `wx.setStorageSync`（微信本地缓存接口，`miniprogram/utils/store.js:30`）容量有限 | 图片存小程序本地永久文件，账目只存文件路径，D9 可清理 |
| 周期账「自动」 | 小程序无后台常驻 | 冷启动 / 回前台补记 + 去重（A6），不做定时推送 |
| 超支「提醒」 | 无订阅消息、无后端 | 页内标红（A4 / C3），不做系统通知 |
| 导出 `CSV` | 小程序无浏览器下载 | 生成文件后转发到微信或复制文本（D8） |
| 老数据兼容 | 现有记录字段固定（`miniprogram/pages/ledger/ledger.js:102`），日期写死今天（`:104`），只能删不能改（`miniprogram/utils/store.js:34`） | 新字段读取时补默认值，不迁移；`month`（月份）按 `date`（日期）重算 |

## 六、数据字段变化

| 新增字段 | 中文 | 用在哪 | 老数据怎么处理 |
|---|---|---|---|
| `bookId` | 账本标识 | A5、D3、B3、C2 | 默认「日常账本」 |
| `account` | 账户 / 支付方式 | A1、D2、B3、C2 | 默认「现金」 |
| `imagePath` | 票据图片路径 | A1、B4、B6、D9 | 空 |

| `templateId` | 模板来源 | A2、D4 | 空 |
| `recurringId` | 周期规则标识 | A6、D5 | 空 |
| `deletedAt` | 删除时间（回收站） | B5 | 空 |

## 七、验收口径

| 编号 | 条件 |
|---|---|
| 1 | 能把一笔账记到昨天，月结页统计跟着落到正确月份 |
| 2 | 任意一笔能改任意字段，改完汇总、占比、预算同步刷新 |
| 3 | 删除后能撤销，撤销后数据与原样一致 |
| 4 | 造 200 笔数据，按分类 + 关键词筛选仍能秒出结果，且不再只显 8 笔 |
| 5 | 模板一键带入全部字段，只改金额即可保存 |
| 6 | 同一周期规则在同一天重复打开，只补记一次 |
| 7 | 导出的 `CSV` 能用表格软件打开，导入后条数与金额一致 |
| 8 | 只读成员看不到任何记 / 改 / 删入口，强行触发也被拦住 |
| 9 | 切账本后，流水、月结、预算都只算当前账本 |
| 10 | 票据能看原图、能清理，清理后账目本身不丢 |
