# 记账功能业务用例设计

| 项 | 内容 |
|---|---|
| 日期 | 2026-11-04 |
| 项目 | 家庭收支本 · 青月版（微信小程序） |
| 存储 | 云端存主本、本机留缓存；换设备、清缓存、重装不丢；离线可先记，联网自动补传 |
| 交付形态 | 业务用例：谁 · 在哪个页面 · 能干什么 · 达到什么目的 |
| 本轮状态 | 设计与静态原型；现有小程序样式与导航已按暖色橘黄调换色，新功能未实现 |
| 修订一 | 2026-11-04：去掉多人协作与成员权限体系，改为「账本分享 + 分享时勾选可否更改」 |
| 修订二 | 2026-11-04：可更改的那一方改动必须留痕（谁、什么时候），全账本增加一条完整操作流水 |
| 修订三 | 2026-11-04：**删掉「纯本地不联网」这条并非用户提出的假设**。该句原写在初始提交 `5e24ba1` 的 `README.md:3` 里，属于初始化时的技术选型，不是需求；用户明确要求联网、数据不能丢。据此改为云端主存，前面因纯本地推导出的副本、回传、本地时间、访问无法留痕等限制全部作废 |

## 一、范围裁定

| 项 | 结论 | 理由 |
|---|---|---|
| 截图 `OCR`（图片文字识别） | 不做 | 用户点名砍掉 |
| 自动同步微信 / 支付宝 / 银行流水 | 不做 | 用户点名砍掉；要登录授权、各家账单格式不一、隐私合规、接口一变就失效 |
| 多币种 | 不做 | 统一人民币 |
| 社区 | 不做 | 与记账无关 |
| `AI`（人工智能） | 不做 | 连带的「语音 / 一句话智能解析」一并砍掉，本质靠 `AI`，不做半吊子 |
| 多人协作 / 成员权限体系 | 不做 | 用户点名砍掉；不邀请、不建成员账号、不设角色 |
| 「纯本地不联网」 | **不是需求，已删** | 见修订三；用户要的是换手机数据别丢 |
| 账本分享 | **做** | 发一条分享链接，当场勾「允许对方更改」；不勾只读，勾了可改，随时能停用 |
| 操作留痕 + 整体操作流水 | **做** | 只读访问、每次改动都记「谁、服务端时间、对哪笔、改前改后」，全账本一份完整流水 |
| 云端主存 + 离线补传 | **做** | 换设备、清缓存、重装都不丢；没网也能记 |
| 除以上不做项 | 全做 | 用户确认「其他的都要」 |

说明：原有 `member`（成员：我 / 家人 / 共同）只是**账目归属标签**，用来做统计，不是账号，也不是协作身份，保留不动。

## 二、角色

| 角色 | 是谁 | 权限边界 |
|---|---|---|
| 使用者 | 拥有这本账的人，同一微信号跨设备 | 记、改、删、看、管配置、发起与停用分享、看操作流水、导出备份 |
| 分享接收方 | 点开分享链接的人，不用注册、不进成员体系 | 按链接权限：只读则只看，可改则能记改删；每次访问与改动由服务端留痕 |
| 系统 | 云端服务 + 小程序自身 | 同步与冲突处理、周期账定时补记、算预算、生成分享链接、记录访问与操作流水 |

## 四、业务用例

| 编号 | 谁 | 在哪个页面 | 可以干什么 | 达到什么目的 |
|---|---|---|---|---|
| A1 | 使用者 | 账本页 | 切支出 / 收入，输金额（支持 `12+8` 直接算），选分类、账户、成员、日期（可补昨天以前）、填备注、附票据照片，点「记下」 | 一次把一笔真实消费记全，不用回家补、不漏字段 |
| A2 | 使用者 | 账本页 | 选模板（买菜 / 通勤 / 工资）一键带入金额、分类、账户、备注，只改金额就存 | 高频固定支出不用每次重填 |
| A3 | 使用者 | 账本页 | 记完保留上次分类、账户、成员，只清金额和备注 | 连着记几笔不重复选 |
| A4 | 使用者 | 账本页 | 顶部看本月收入 / 支出 / 结余、预算剩余，超支标红 | 记之前就知道这个月还剩多少能花 |
| A5 | 使用者 | 账本页 | 切当前账本（日常 / 旅行 / 装修） | 专项花费不混进家庭日常账 |
| A6 | 系统 | 账本页 / 云端 | 按周期规则定时补记到期账（房租、工资），同日同规则只补一次；不依赖打开小程序 | 固定收支不因忘记打开而漏记 |
| A7 | 使用者 | 账本页 | 点最近几笔进详情，直接编辑或删除 | 记错当场改，不用翻二级页 |
| A8 | 使用者 → 系统 | 账本页 | 没网也能记，先写本机缓存并显示「待同步」；联网后自动补传云端，流水不丢一条 | 地铁、地库、信号差照样记，且不丢数据 |
| A9 | 使用者 | 账本页 | 换手机 / 重装后用同一微信号打开，云端账目、分类、模板、操作流水自动回来 | 换设备、清缓存、删小程序都不丢账 |
| B1 | 使用者 / 分享接收方 | 流水页 | 按日分组看全部账目（不再只显 8 笔），每日小计收入 / 支出 | 完整还原钱怎么花的 |
| B2 | 使用者 / 分享接收方 | 流水页 | 日历视图点某天看当天明细、跨天补记 | 对账、想起漏记的那天 |
| B3 | 使用者 / 分享接收方 | 流水页 | 按分类 / 成员 / 账户 / 账本 / 类型 / 日期 / 金额区间 / 关键词筛选 | 从几百笔里一秒找到「上周给爸买药那笔」 |
| B4 | 使用者 / 分享接收方（限可改链接） | 流水页 | 编辑任意一笔：金额、分类、账户、成员、日期、备注、票据 | 记错、选错、输错都能纠正 |
| B5 | 使用者 / 分享接收方（限可改链接） | 流水页 | 删除后 5 秒内撤销，或进回收站保留 7 天 | 手滑删了不丢数据 |
| B6 | 使用者 / 分享接收方 | 流水页 | 点开票据照片看原图 | 核对小票、报销有凭 |
| B7 | 分享接收方 | 流水页（云端同一本账） | 按链接权限：不勾只读，记改删入口全隐藏且服务端拒绝写入；勾了可改就能记改删，每次改动由服务端记下署名、时间、改前改后 | 只读是真只读，可改是笔笔留痕，谁在什么时候动的说得清 |
| C1 | 使用者 / 分享接收方 | 月结页 | 左右切月份，看收入 / 支出 / 结余、笔数 | 月底复盘有个准数 |
| C2 | 使用者 / 分享接收方 | 月结页 | 按分类 / 成员 / 账户 / 账本看支出占比与排行 | 知道钱主要花在哪个口子、谁花的 |
| C3 | 使用者 / 分享接收方 | 月结页 | 看总预算与分类预算执行、超支标红、对比上月趋势 | 下个月知道该收哪一刀 |
| C4 | 使用者 | 月结页 | 点分类下钻到该分类的流水 | 从「伙食花了 2000」直接看到哪笔记多了 |
| D1 | 使用者 | 设置页 | 增删改分类（名称 / 图标 / 颜色 / 排序），支出收入各一套 | 分类贴合自家口径，不再被写死的 7 + 5 个困住 |
| D2 | 使用者 | 设置页 | 管账户（现金 / 微信 / 支付宝 / 银行卡），可停用不删历史 | 记账能选资金出处，停用旧卡不丢旧账 |
| D3 | 使用者 | 设置页 | 管账本（建 / 改名 / 切换 / 删，删除二次确认并说明数据去向） | 旅行、装修专项账分开算 |
| D4 | 使用者 | 设置页 | 管模板（把常记的一笔存成模板、排序、删除） | 把 A2 的提速能力自己攒出来 |
| D5 | 使用者 | 设置页 | 管周期账（金额 / 分类 / 账户 / 周期 / 起始日 / 启停） | 房租、工资、话费不用月月手敲 |
| D6 | 使用者 | 设置页 · 分享账本弹层 | 选账本 → 勾「允许对方更改」→ 给访问者填个署名（用于留痕，如「家人」）→ 选可见范围 → 生成分享链接 → 转发微信 | 不建账号、不拉人协作，一条链接把账交出去，改不改当场定 |
| D7 | 使用者 | 设置页 | 设总预算、各分类预算、超支提醒开关 | 把 A4 / C3 的阈值定下来 |
| D8 | 使用者 | 设置页 | 导出 `CSV`（逗号分隔表格，按时间 / 账本筛选）并转发或复制，可导入恢复 | 云端之外再多一层保险 |
| D9 | 使用者 | 设置页 | 看云端占用、清理票据图片、清空账本数据（操作流水只追加不随清空消失） | 存储不被图片撑爆，留痕不被顺手抹掉 |
| D10 | 分享接收方 | 微信里点开分享链接 | 不用注册、不用导入文件，按权限直接看同一本云端账；只读就只看，可改就能补能改 | 拿到就能看或就能补，不用折腾文件来回传 |
| D11 | 使用者 | 设置页 · 分享管理 | 看已发出的链接、权限、访问与改动记录；可改权限或一键停用 | 随时收回，不留后门 |
| E1 | 使用者 / 分享接收方 | 操作流水页 | 按时间倒序看整本账从建账到现在的全部操作：谁、服务端时间、对哪笔、做了什么（访问 / 记一笔 / 改 / 删 / 分享 / 停用 / 补记 / 同步）、改前值改后值 | 账上任何变动、谁来看过，都能追到人追到时间 |
| E2 | 使用者 / 分享接收方 | 操作流水页 | 按操作人、动作类型、时间范围、关键词筛选，点一条跳到对应那笔账 | 几百条流水里一秒定位「这数是谁改的」 |
| E3 | 使用者 | 操作流水页 | 单独导出操作流水 | 留档、对账有凭 |
| E4 | 系统 | 云端 + 所有写操作处 | 每次访问 / 新增 / 修改 / 删除 / 撤销 / 分享 / 停用 / 导入 / 补记 / 同步，自动追加一条流水：只追加，界面不提供编辑删除，账目删了流水仍在 | 留痕靠系统自动记，不靠人自觉，也抹不掉 |

## 五、约束与落地替代

| 想做的事 | 依据 / 约束 | 落地办法 |
|---|---|---|
| 数据不丢 | 用户明确要求换手机、清缓存也不能没 | 云端存主本、本机 `wx.setStorageSync`（微信本地缓存接口）只作离线暂存；同一微信号跨设备自动同步；`README.md:3` 与 `README.md:12` 已按此改写 |
| 「别人访问」 | 有云端主本，不再需要发文件、导副本 | 分享链接指向同一本云端账，权限由链接携带，服务端校验；只读链接连写请求也拒绝 |
| 访问留痕 | 服务端能记 | 只读访问也留一条「谁、什么时候、看了哪本」；之前「做不到」的说法作废 |
| 「谁」怎么来 | 不建账号、不拿微信昵称，用户也不要协作体系 | 分享时填署名写进链接权限 `actor`（操作人署名）；这是留痕标识，不是实名认证 |
| 「什么时候」 | 服务端统一时间 | 用服务端时间，不再受手机本地时间影响 |
| 整体操作流水 | 云端集中存 | 本机、分享接收方的动作都汇进同一份流水，不用回传、不用合并 |
| 多人协作仍不做 | 用户点名砍掉 | 不邀请、不建成员体系、不设角色；只有一条可随时停用的分享链接加一个权限开关 |
| 并发冲突 | 两边可能同时改同一笔 | 服务端按时间后改覆盖，双方版本都写进流水，不静默丢；冲突条目在 E2 可筛出 |
| 云端选型 | 当前 `project.config.json:7` 是 `touristappid`（游客测试号） | 建议微信云开发（云端数据库 + 云函数），需绑正经 `AppID`（小程序账号标识）、开通云环境；也可换自建后端，用例不变 |
| 票据照片 | 图片不适合塞本机缓存 | 存云端文件，账目只存路径，D9 可清理 |
| 周期账「自动」 | 有云端定时能力 | 由云端定时触发补记（A6），不再依赖打开小程序 |
| 超支「提醒」 | 订阅消息要用户授权 | 仍做页内标红（A4 / C3），不强制推送 |
| 被砍掉的那几项 | 用户点名 | 语音 / 一句话 / `OCR` / 银行流水自动同步 / 多币种 / 社区 / `AI` 一律不做；**云端同步的是自己记的账，不是去抓支付账单** |
| 老数据兼容 | 现有记录字段固定（`miniprogram/pages/ledger/ledger.js:102`），日期写死今天（`:104`），只能删不能改（`miniprogram/utils/store.js:34`） | 新字段读取时补默认值，不迁移；`month`（月份）按 `date`（日期）重算；老账目不伪造历史流水 |

## 六、数据字段变化

| 新增字段 | 中文 | 用在哪 | 老数据怎么处理 |
|---|---|---|---|
| `bookId` | 账本标识 | A5、D3、B3、C2、D6 | 默认「日常账本」 |
| `account` | 账户 / 支付方式 | A1、D2、B3、C2 | 默认「现金」 |
| `imagePath` | 票据图片云端路径 | A1、B4、B6、D9 | 空 |
| `updatedAt` | 最后修改时间（服务端） | B4 | 取 `createdAt`（创建时间） |
| `templateId` | 模板来源 | A2、D4 | 空 |
| `recurringId` | 周期规则标识 | A6、D5 | 空 |
| `deletedAt` | 删除时间（回收站） | B5 | 空 |
| `syncedAt` | 同步到云端的时间 | A8、A9 | 空表示待同步 |
| `editable` | 可否更改（**分享链接权限标记，不进账目记录**） | D6、D10、B7 | 无老数据；缺省按只读处理 |
| `actor` | 操作人署名（**分享链接与流水共用，不进账目记录**） | D6、B7、E1、D11 | 缺省「本机使用者」 |
| `operations` | 操作流水集合（**云端集合，不进单条账目**） | E1–E4、D11 | 老数据补空集合，已有账目不伪造历史 |

`operations` 每条含：`id`（流水号）、`actor`（谁）、`at`（服务端时间）、`action`（动作）、`entryId`（哪笔账）、`before`（改前值）、`after`（改后值）、`source`（来源：本机 / 分享链接）。

## 七、验收口径

| 编号 | 条件 |
|---|---|
| 1 | 能把一笔账记到昨天，月结页统计跟着落到正确月份 |
| 2 | 任意一笔能改任意字段，改完汇总、占比、预算同步刷新 |
| 3 | 删除后能撤销，撤销后数据与原样一致 |
| 4 | 造 200 笔数据，按分类 + 关键词筛选仍能秒出结果，且不再只显 8 笔 |
| 5 | 模板一键带入全部字段，只改金额即可保存 |
| 6 | 同一周期规则在同一天只补记一次 |
| 7 | 导出的 `CSV` 能用表格软件打开，导入后条数与金额一致 |
| 8 | 分享时不勾「允许更改」，对方打开看不到记 / 改 / 删入口，直接发写请求也被服务端拒绝 |
| 9 | 切账本后，流水、月结、预算都只算当前账本 |
| 10 | 票据能看原图、能清理，清理后账目本身不丢 |
| 11 | 一键停用分享链接后，原链接立刻打不开，停用动作写进操作流水 |
| 12 | 可改链接里改一笔，操作流水立刻多一条，含署名、服务端时间、动作、改前改后 |
| 13 | 操作流水只能追加，界面没有编辑删除入口；账目删了流水还在，清账本数据也还在 |
| 14 | 只读链接打开一次，操作流水留下一条访问记录（谁、服务端时间、看了哪本） |
| 15 | 断网记一笔，联网后自动补传，条数、金额、流水都不丢 |
| 16 | 换设备用同一微信号登录，账目、分类、模板、操作流水条数与金额完全一致 |
